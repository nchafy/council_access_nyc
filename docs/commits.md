# Commits

Measured on `feat/m5-a11y-perf`: 37 commits, **median 3 files and 128 changed lines**. That
median is the target.

## Size

**One commit, one claim.** If the message needs "and", it is two commits.

| Rule | Why |
|---|---|
| ≤ 5 files, ≤ ~300 lines | past that a reviewer reads the message instead of the diff |
| Vendored or generated bytes commit alone | a 567 KB blob buries the 40 lines beside it |
| Renames and mechanical sweeps commit alone | so the real change stays reviewable |

**Commit the guard before the thing it guards.** `test_template_safety.py` landed before Jinja2;
the large-frame test before the WebSocket swap. Both pass against the old code — a guard written
afterwards describes what you built instead of constraining it.

**A correction gets its own commit.** Four claims were wrong on this branch; each was fixed in a
commit naming the error. Amending hides the most useful part.

## Message

`type(scope): imperative summary`, ≤ 72 chars. Types in use: `feat` `fix` `test` `refactor`
`docs` `chore` `ci` `copy`. TDD markers: `test: … (RED)` then `feat(scope): … (GREEN)`.

**The body carries the reasoning.** This repo strips comments from code, so the "why" has to
live here — 1,099 body lines across 37 commits is the real ratio.

State: what was wrong (the measurement, not the adjective) · what changed, and what you
deliberately did not · which gates ran and which numbers moved, before → after · what you
refused · **what you could not verify**.

Write for whoever reopens this in two years.

### Anti-patterns

- "Minor fixes", "cleanup" — names no claim, so nothing can be checked.
- Restating the diff in prose.
- An adjective where a number belongs. "Much faster" is unreviewable; "869 ms p95 against a
  3,000 ms threshold" is.
- Claiming a gate ran when it did not.

## Before committing

```bash
uv run ruff check . && uv run ruff format --check .
uv run pytest -m "not upstream and not browser" -q      # 100% coverage enforced
```

Touched the renderer, assets, headers or a source: add `make build && uv run python
scripts/verify.py`. Touched anything a reader sees: add `make gates` — `make verify` excludes the
four browser gates, so it is necessary and not sufficient (`.claude/skills/validate/SKILL.md`).

**Never commit:** `etl/raw/`, `site/`, a secret, or a loosened threshold. Thresholds live in
`perf-budget.json`; changing one is its own commit with a reason.
